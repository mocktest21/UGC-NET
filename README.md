# MockMaster — Module 1: Public Website

A responsive public website foundation for MockMaster, a competitive-examination practice platform.

## Included in this module

- Homepage with hero, dashboard preview, examination categories, sample popular tests and feature sections
- Responsive navigation and multi-column footer
- Examination landing pages for UGC NET, SSC, UPSC, Banking and Railways
- Mock-test listing landing page
- Previous-year-question landing page
- About and contact pages
- Privacy Policy, Terms & Conditions, Cookie Policy and Disclaimer starter pages
- Branded 404 page
- Search form and search-results placeholder
- Automatic light/dark theme based on device preference
- Brand palette based on the supplied Figma palette screenshot

## Technology

- Next.js App Router
- React
- TypeScript
- CSS design system

## Run locally

Install Node.js, then run:

\`\`\`bash
npm install
npm run dev
\`\`\`

Open http://localhost:3000.

## Upload to GitHub

Upload the contents of this folder to the root of the `mocktest21/UGC-NET` repository, keeping the folder structure intact. Do not upload the outer ZIP itself as the only repository file.

## Important notes

- The dashboard in the homepage hero is illustrative. Its figures are sample values, not live student data.
- Authentication, Supabase integration, admin tools, question bank, test engine and analytics are intentionally deferred to later modules.
- Legal pages are starter placeholders and require final review and operational details before public launch.
- No API keys, passwords or private credentials are included.
